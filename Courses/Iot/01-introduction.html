Module 01 — Introduction to IoT

⏱ 2 hours 📚 5 lessons 🎯 Beginner 🧪 1 project

Welcome to the Internet of Things! In this module, you'll understand what IoT actually is (beyond the buzzword), how connected devices work together, and how to set up everything you need to start building.

💡 What you'll learn

What IoT is, the 4-layer architecture, common protocols, and how to prepare your development environment.

1.1 What is IoT?

The Internet of Things (IoT) is the network of physical devices — sensors, appliances, machines, wearables — that are connected to the internet and can collect, share, and act on data.

Examples you already use:

  • Smart home: Alexa, Google Home, smart bulbs, thermostats
  • Wearables: Fitness bands, smartwatches
  • Industry: Predictive maintenance sensors on factory machines
  • Agriculture: Soil moisture monitors that trigger irrigation
  • Healthcare: Remote patient monitoring devices
📌 Key idea

IoT is not just "devices connected to the internet." It's the full loop: sense → transmit → process → act.

1.2 The IoT Architecture (4 Layers)

Every IoT system, from a smart bulb to a smart city, fits into these four layers:

  1. Perception Layer — Sensors and actuators that interact with the physical world
  2. Network Layer — Wi-Fi, Bluetooth, LoRaWAN, cellular that transmit data
  3. Processing Layer — Cloud or edge computing that analyzes and stores data
  4. Application Layer — Dashboards, apps, and alerts users interact with

1.3 Common IoT Protocols

Devices speak many "languages." Here are the ones you'll actually use:

  • MQTT — Lightweight pub/sub. Ideal for low-power devices. ⭐ Most popular
  • HTTP/REST — Familiar but heavier. Fine for occasional updates.
  • CoAP — Like HTTP but designed for constrained devices.
  • BLE (Bluetooth Low Energy) — Short-range, low-power. Great for wearables.
  • LoRaWAN — Long-range, low-power. Used in smart agriculture and cities.
  • Zigbee / Z-Wave — Mesh networks for smart homes.
✅ Rule of thumb

If you're unsure which protocol to use, start with MQTT over Wi-Fi. It covers 80% of hobby and small commercial projects.

1.4 Hardware & Software You'll Need

You don't need expensive gear to get started. Here's the minimum:

  • Microcontroller: ESP32 (~$5) or Arduino Uno (~$15)
  • Sensors: DHT22 (temp/humidity), PIR (motion), ultrasonic (distance)
  • Breadboard + jumper wires — for prototyping without soldering
  • USB cable — to connect your board to your computer

Free software we'll use:

  • Arduino IDE or PlatformIO (VS Code extension)
  • MQTT Explorer — visual MQTT client
  • Node-RED — drag-and-drop IoT flow builder
  • Free MQTT broker: HiveMQ, EMQX, or Mosquitto
⚠ No hardware yet?

That's fine! We'll use Wokwi and Tinkercad Circuits — free online simulators — so you can follow along without buying anything.

1.5 Setting Up Your Dev Environment

  1. Download and install Arduino IDE from arduino.cc
  2. Add ESP32 board support (Preferences → Additional Board URLs)
  3. Install the PubSubClient and DHT sensor libraries
  4. Plug in your ESP32 and select the correct board + port
  5. Upload the classic Blink example to verify everything works
blink.ino
void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  delay(1000);
  digitalWrite(LED_BUILTIN, LOW);
  delay(1000);
}

If your LED blinks, your environment is ready. ✅

🎯 Mini Project — Blink an LED

Your first IoT "hello world": make the built-in LED on your ESP32 blink once per second. Then modify the code to blink in an SOS pattern (3 short, 3 long, 3 short).

Key Takeaways

  • IoT = devices + network + cloud + apps, forming a sense → transmit → process → act loop
  • Every IoT system has 4 layers: Perception, Network, Processing, Application
  • MQTT is the most important protocol for IoT — you'll use it constantly
  • ESP32 is the best beginner board: cheap, powerful, Wi-Fi + Bluetooth built-in
  • You can start without hardware using free simulators
